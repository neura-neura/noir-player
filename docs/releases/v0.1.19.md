Noir Player 0.1.19 adds saved subtitle styles and progressive WebVTT captions.

### Subtitle styles

- Save, apply, rename, update, and delete custom styles. Saved styles persist across app restarts and include every visual setting and the CSS font source.
- Choose from two included styles: the original **Noir Player** preset and **Anime Classic**, with bold white lettering, a black outline, and no background box.
- Adjust outline thickness from 0 to 8 px and choose its color in the Style panel. Both settings are saved with custom styles.

### Caption playback fixes

- WebVTT captions with inline timestamps now reveal words progressively while keeping the caption position stable. Pausing and seeking restore the text for the current playback time.
- Captions without word timestamps retain their original line timing; word timing is not estimated.
- Fixed missing opening captions in some subtitle tracks extracted from MP4 files.
- Removed an internal plugin counter that could appear as a stray number in the interface.

### Windows installation

Download the Windows x64 setup executable below and run it to install or update Noir Player. An MSI installer is also available.
